# leafletbasemapcustomrouting
Leaflet-Karte mit Basemap, Custom Layer und Routing entlang definierter Wege (z. B. Objekte auf einer Wiese)

## Nutzung

`index.html` im Browser öffnen. Durch Klick auf eine Sehenswürdigkeit werden Details
angezeigt und die Route vom nördlichen Eingang entlang der definierten Wege berechnet.

Alternativ kann ein einfacher lokaler Server gestartet werden, z. B.:

```
npx http-server
```

Danach die ausgegebene URL im Browser öffnen.
